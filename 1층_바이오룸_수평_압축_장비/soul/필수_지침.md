# 1층 바이오룸용 수평 압축 장비 필수 지침

이 문서는 이 장비의 코드와 문서를 수정하거나 시험할 때 반드시 먼저 읽고 따라야 하는 운영 지침이다.

## 장비 식별

- 설치 장소: 1층 바이오룸
- 장비 형태: 수평 압축 장비
- 메인보드: Arduino Mega 2560
- 확장 보드: RAMPS 1.4 Shield
- 스텝 모터: 14HR08-0654S
- 스텝 모터 드라이버: A4988
- 로드셀: BCL-3L
- 로드셀 인디케이터: CI-1580A

## 작업 전 필수 확인

1. 이 문서와 장비 폴더의 `history.md`를 먼저 읽는다.
2. 수정 대상이 1층 수평 장비인지 4층 수직 장비인지 확인한다.
3. 핀 번호, 통신 속도, 이동 방향, `steps/mm`, 속도 및 가속도 제한을 추측해서 변경하지 않는다.
4. 기존 사용자 파일과 측정 데이터를 임의로 삭제하거나 덮어쓰지 않는다.
5. 코드 변경 전 현재 동작과 관련 파일을 확인하고 변경 범위를 최소화한다.

## 안전 원칙

1. 비상 정지 수단, 이동 경로, 압축판 주변 및 시편 고정 상태를 확인하기 전에는 모터를 구동하지 않는다.
2. 장비에 사람이 접근 중이거나 충돌 가능성이 있으면 자동 이동과 조그 이동을 실행하지 않는다.
3. 최초 시험은 낮은 속도와 짧은 거리로 수행한다.
4. 이동 방향을 확인하지 않은 상태에서 큰 거리 명령을 보내지 않는다.
5. 로드셀 영점과 단위를 확인하고 허용 하중을 넘는 시험을 하지 않는다.
6. 실제 장비가 연결되지 않은 경우 하드웨어 구동을 확인했다고 기록하지 않는다.

## 작업 후 필수 검증

1. 프로그램을 직접 실행해 시작 화면이 정상적으로 열리는지 확인한다.
2. 가능한 경우 문법 검사, 빌드 또는 펌웨어 컴파일을 수행한다.
3. 장비가 연결된 경우 포트 연결, 수동 조그, 정지, 짧은 자동 이동, 로드셀 표시, CSV 저장을 단계별로 확인한다.
4. 장비가 연결되지 않았으면 GUI 실행 및 정적 검사까지만 검증하고 그 한계를 명확히 보고한다.
5. 실제 모터 구동은 작업자 입회와 안전 확인 후 수행한다.
6. 완료 후 `history.md`에 날짜, 변경 내용, 구현 기능, 실행한 검증, 미검증 항목과 알려진 문제를 기록한다.

## 보고 원칙

- “프로그램 실행 성공”, “통신 연결 성공”, “모터 실제 이동 성공”, “로드셀 실제 측정 성공”을 구분해서 보고한다.
- 실행하지 않은 시험을 성공했다고 표현하지 않는다.
- 오류나 위험 요소를 발견하면 숨기지 않고 파일과 증상을 함께 기록한다.
