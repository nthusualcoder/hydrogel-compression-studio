# 작업 이력 및 구현 현황

## 현재 장비 구성

- Arduino Mega 2560 + RAMPS 1.4 Shield
- 14HR08-0654S 스텝 모터
- A4988 스텝 모터 드라이버
- BCL-3L 로드셀
- CI-1580A 로드셀 인디케이터

## 현재 구현 현황

- 이 폴더에는 아직 1층 수평 압축 장비 전용 실행 코드가 배치되지 않았다.
- `v1/file/기존 코드/아두이노 코드/아두이노 코드.ino`에는 RAMPS 1.4용으로 보이는 초기 Arduino 코드가 있다.
- 해당 초기 코드는 STEP 60, DIR 61, ENABLE 56, STOP 3 핀과 9600 bps 통신을 사용한다.
- 4층 장비용 GUI와의 통신 속도 및 조그 명령 호환 여부는 아직 검증되지 않았다.

## 작업 이력

### 2026-06-09

- 1층 바이오룸용 수평 압축 장비 폴더를 생성했다.
- 장비 구성과 필수 안전·검증·보고 원칙을 `soul/필수_지침.md`에 기록했다.
- 기존 `v1` 코드에서 RAMPS 1.4 관련 초기 펌웨어의 존재를 확인했다.
- 1층 장비 전용 프로그램은 아직 없으므로 프로그램 실행 및 하드웨어 구동 검증은 수행하지 못했다.
- 현재 환경에는 사용할 수 있는 Python 및 Arduino CLI가 없어 기존 초기 펌웨어의 컴파일 검증도 수행하지 못했다.

### 2026-06-15

- 1층 수평 압축 장비 제어 프로그램 v2 버전을 새로 설계 및 작성하여 `v2/` 폴더에 배치했다.
  - 아두이노 펌웨어: `v2/compression_arduino/compression_arduino.ino`
  - GUI 프로그램: `v2/compression_v2.py`
- 수동 포트 연결 해제 기능을 지원하기 위해 "연결 해제" 버튼을 추가하고 시리얼 객체 자원 해제 코드를 구현했다.
- 포트 번호 기본값 편의를 제공하고자 `config.json` 연동 저장/불러오기 기능을 추가했다.
- 아두이노 시리얼 비동기 수신 스레드를 도입하여, 아두이노의 완료(`"DONE"`) 및 비상 정지(`"STOP_BUTTON"`) 신호를 캐치하여 GUI 내부 측정 프로세스와 결합시켰다.
- Antigravity 디자인 가이드를 적용하여 모던 카드형 레이아웃으로 UI를 전면 개선하였고, 실시간 다크/라이트 테마 스위칭 및 그래프 색상 실시간 동기화 기능을 구현했다.
- "조그 속도"의 UI 텍스트 명칭을 직관적인 "이동 속도"로 수정했다.
- 힘 그래프 Y축 스케일링을 데이터의 실시간 최대/최소값에 맞춰 능동적으로 정밀 스케일링되도록 로직을 고도화했다. (초기 디폴트 마진인 -0.2 ~ 1.0 N 범위는 보존)
- 복잡한 다크/라이트 테마 전환 방식을 제거하고, 시인성이 높고 장시간 모니터링에도 편안한 부드러운 웜 라이트 테마(Warm Light Theme)로 화면을 단일 고정했다.
- 자동 측정 카드 내부의 "시험 속도(mm/s):" 라벨 명칭을 수동 제어와 일관되게 "이동 속도(mm/s):"로 변경했다.
- Tkinter 캔버스를 확장 상속한 `RoundedButton` 위젯 클래스를 자체 구현하여, 4개의 꼭짓점이 8px 반경으로 완벽하게 동그랗게 깎인 현대적인 플랫 버튼을 GUI 전반에 배치했다.
- 왼쪽 제어부 프레임의 전체 폭을 360px에서 390px로 넉넉하게 넓히고 경로 출력의 길이 제한을 최적화하여, 1~4번 카드 프레임 내부 컴포넌트들이 박스 밖으로 삐져나가는 레이아웃 탈출 현상을 완벽히 해결했다.
- 최종 검증 완료된 `compression_v2.py` 스크립트를 PyInstaller를 이용하여 콘솔창이 차단된 단일 실행 파일 (`v2/compression_v2.exe`)로 성공적으로 빌드하고, 빌드 부산물(build, dist, spec)을 삭제하여 깔끔하게 배포 정리했다.
- 로컬 PC 내 컴파일 환경(파이썬, 아두이노) 부재로 정적 코드 리뷰 및 분석 위주의 검증을 수행했다. 실장비 모터 구동은 추후 작업자 입회 하에 실차 검증이 필요하다.

### 2026-09-03 · v3 작성

- `v3/` 폴더에 1층 전용 제어 프로그램을 새로 작성했다. `v1`, `v2`는 수정하지 않고 보존했다.
  - GUI: `v3/hydrogel_app/` (장비 설정은 `profile.py` 한 파일: 조그 `JF`/`JB`, 키보드 ←/→, 기본 포트 COM3/COM4, 로드셀 3 kg)
  - 펌웨어: `v3/firmware/compression_1F_mega_ramps/compression_1F_mega_ramps.ino`
  - 실행 파일: `v3/HydrogelStudio_1F.exe`
- 사용자 확인 사항 반영: 인디케이터는 단위 문자 없이 `xxx.x`(g)로 보내고 압축 시 음수이며, `JF`(전진)가 누르는 방향이고 800 steps/mm는 실측 확인됨.
- 버그 수정: v2 파서는 줄에 `kg`/`g` 문자가 있어야만 값을 읽어 실제 형식(`xxx.x`)을 읽지 못했다. 부호 반전을 적용해 압축력을 양수 N으로 표시한다.
- 버그 수정: Poroelasticity 모드가 모터 `DONE`과 함께 기록을 끝내던 동작을 고쳐, 목표 거리 도달 후에도 변위를 유지한 채 계속 기록한다.
- 동작 변경: `STOP`(비상 정지) 시 드라이버 전원을 끄지 않고 위치를 유지한다. 전원 차단은 별도 `MOFF` 명령(모터 전원 OFF 버튼)으로 분리했고 `MON`으로 재인가한다.
- 펌웨어 v3: 핀(60/61/56, 비상정지 D3), 통신 속도, steps/mm, 속도·가속도 상한은 v2와 동일하다. `MOFF`/`MON` 명령, `` 무시, 속도 상한 클램프, 즉시 정지(`haltNow`)를 추가했다.
- 이동 완료 판정을 Arduino `DONE` 신호 기준으로 바꾸고, 신호를 놓치면 예상 시간의 1.5배 + 2초 후 시간 기준으로 보조 판정한다.
- UI를 VS Code Dark+/Light+ 스타일(타이틀 바, 사이드바, 파란 상태 바)로 전면 재작성했다. 최대 하중 표시, 로드셀 용량 90% 경고, 설정 자동 저장(`%APPDATA%\HydrogelStudio\settings_1F.json`)을 추가했다.
- 검증: Python 3.10.11에서 문법 검사와 자동 테스트 9개(명령 생성, 파서, 설정 저장, 조그/시험/비상정지/전원 버튼 신호, 하드웨어 정지 신호, Poroelasticity 유지 기록) 통과. `--demo` 가상 장비로 밝은/어두운 테마 화면을 캡처해 레이아웃을 확인했다.
- 빌드: PyInstaller(`build.spec`)로 `v3/HydrogelStudio_1F.exe`를 생성하고 `--demo`로 실행해 창이 뜨고 응답하는 것을 확인했다.
- 미검증: 로컬에 Arduino CLI가 없어 펌웨어 컴파일을 하지 못했다. 실장비 포트 연결, 모터 이동, 로드셀 측정은 수행하지 않았다. v2 펌웨어와도 `start`/`JF`/`JB`/`STOP`/`DONE`은 호환되지만 `MOFF`/`MON`은 새 펌웨어를 올려야 동작한다.

- 기능 추가: 타이틀 바에 **⬇ 업데이트 확인 (v3.0.0)** 버튼을 추가했다. GitHub Releases(`nthusualcoder/hydrogel-compression-studio`)의 최신 태그를 조회해 현재 버전보다 높으면 `HydrogelStudio_1F.exe`를 실행 파일 옆에 내려받고, 원하면 실행 중인 exe를 교체한 뒤 다시 실행한다(기존 파일은 .bak 보관). 새 모듈 `hydrogel_app/updater.py`.

### 2026-09-22 · v3.0.1 전체 검증 및 수정

- **거리 추정 오차 수정**: 거리 = 경과시간 × 속도 계산이 펌웨어 가속 구간(2.5 mm/s²)을 무시해 1 mm/s에서 약 0.2 mm를 과대평가했다. 새 `hydrogel_app/motion.py`가 펌웨어와 같은 사다리꼴 프로파일로 위치를 계산한다.
- **평균 기록 시 거리 짝 오류 수정**: 평균 힘을 버킷 끝 시각의 거리와 짝지어 저장하던 것을 시각·거리·힘 함께 평균으로 바꿨다.
- 시험 중 0점 변경 차단. 이동·조그 속도가 펌웨어 상한(5000 steps/s = 6.25 mm/s)을 넘으면 시작 거부.
- CSV를 매 줄 flush. 업데이트 교체 배치를 한글 경로 안전(CP949)·PID 정확 일치로 수정하고 실제 교체 동작 시험 통과. 시험 중에는 교체를 제안하지 않는다.
- 검증: 단위 테스트 17개 통과. exe 재빌드, v3.0.1 릴리스.
