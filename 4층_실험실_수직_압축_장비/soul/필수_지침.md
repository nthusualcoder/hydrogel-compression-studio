# 4층 실험실용 수직 압축 장비 필수 지침

이 문서는 이 장비의 코드와 문서를 수정하거나 시험할 때 반드시 먼저 읽고 따라야 하는 운영 지침이다.

## 장비 식별

- 설치 장소: 4층 실험실
- 장비 형태: 수직 압축 장비
- 기존 기준 코드: 이 장비 폴더의 `v1` 폴더
- 현재 개발 코드: 이 장비 폴더의 `v2` 폴더
- 메인보드: Arduino UNO R4 Minima
- 스텝 모터: 14HR08-0654S
- 스텝 모터 드라이버: A4988
- 로드셀: BCL-2L
- 로드셀 인디케이터: CI-1580A

## 코드에서 확인된 현재 연결 규약

- PC GUI 모터 포트 기본값: COM10
- PC GUI 인디케이터 포트 기본값: COM11
- GUI의 모터 통신 속도: 115200 bps
- GUI `main.py`의 인디케이터 통신 속도: 115200 bps
- Arduino 펌웨어 `final.ino` 통신 속도: 115200 bps
- Arduino 핀: DIR 2, STEP 3
- 환산값: 800 steps/mm
- 펌웨어 기본 최대 속도: 4000 steps/s
- 펌웨어 가속도: 2000 steps/s²
- 명령: `start,거리(mm),속도(mm/s)`, `JU,속도`, `JD,속도`, `STOP`

포트 번호, 인디케이터 통신 속도, 이동 방향 및 800 steps/mm 값은 실제 장비 설정과 반드시 대조한다.

## 작업 전 필수 확인

1. 이 문서와 장비 폴더의 `history.md`를 먼저 읽는다.
2. 기존 동작 비교 시 `v1/file/main.py`와 `v1/file/final/final.ino`를 확인한다.
3. 신규 UI와 PC 제어 코드는 `v2`에서만 수정하고 `v1`은 비교 기준으로 보존한다.
4. 핀 번호, 통신 속도, 이동 방향, `steps/mm`, 속도 및 가속도 제한을 추측해서 변경하지 않는다.
5. 기존 사용자 파일과 `v1/file/데이터`의 측정 데이터를 임의로 삭제하거나 덮어쓰지 않는다.
6. 코드 변경 전 현재 동작과 관련 파일을 확인하고 변경 범위를 최소화한다.

## 안전 원칙

1. 비상 정지 수단, 상·하 이동 한계, 압축판 주변 및 시편 고정 상태를 확인하기 전에는 모터를 구동하지 않는다.
2. 장비에 사람이 접근 중이거나 충돌 가능성이 있으면 자동 이동과 조그 이동을 실행하지 않는다.
3. 최초 시험은 낮은 속도와 짧은 거리로 수행한다.
4. 수직축의 상승·하강 방향을 확인하지 않은 상태에서 큰 거리 명령을 보내지 않는다.
5. 로드셀 영점과 단위를 확인하고 허용 하중을 넘는 시험을 하지 않는다.
6. 실제 장비가 연결되지 않은 경우 하드웨어 구동을 확인했다고 기록하지 않는다.

## 작업 후 필수 검증

1. 프로그램을 직접 실행해 시작 화면이 정상적으로 열리는지 확인한다.
2. 가능한 경우 Python 문법 검사, 실행 파일 시작 검사 및 Arduino 펌웨어 컴파일을 수행한다.
3. 장비가 연결된 경우 포트 연결, 수동 조그, 정지, 짧은 자동 이동, 로드셀 표시, 그래프 및 CSV 저장을 단계별로 확인한다.
4. 장비가 연결되지 않았으면 GUI 실행 및 정적 검사까지만 검증하고 그 한계를 명확히 보고한다.
5. 실제 모터 구동은 작업자 입회와 안전 확인 후 수행한다.
6. 완료 후 `history.md`에 날짜, 변경 내용, 구현 기능, 실행한 검증, 미검증 항목과 알려진 문제를 기록한다.
