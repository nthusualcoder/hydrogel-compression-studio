# 작업 이력 및 구현 현황

## 현재 장비 구성

- Arduino UNO R4 Minima
- 14HR08-0654S 스텝 모터
- A4988 스텝 모터 드라이버
- BCL-2L 로드셀
- CI-1580A 로드셀 인디케이터
- 기존 기준 코드 위치: `v1`
- 현재 개발 코드 위치: `v2`

## 현재 구현 현황

- Tkinter 기반 PC GUI가 모터 제어 보드와 로드셀 인디케이터에 각각 직렬 연결한다.
- 수동 상승·하강 조그와 정지 명령을 지원한다.
- 거리와 속도를 지정한 자동 압축 이동을 지원한다.
- 압축 강도 모드에서 거리-하중 그래프를 표시한다.
- Poroelasticity 모드에서 시간-하중 그래프를 표시한다.
- 로드셀 표시값을 g에서 N으로 환산하고 소프트웨어 영점을 적용한다.
- 시간, 거리, 하중을 CSV로 저장한다.
- Arduino 펌웨어는 AccelStepper로 STEP/DIR 방식 A4988을 제어한다.
- v2는 Codex 스타일의 밝은/어두운 카드형 UI, 오렌지 강조색, 연결 상태 및 실행 상태 표시를 사용한다.
- v2는 모터 포트, 로드셀 포트, 저장 폴더와 화면 테마를 JSON 기본값으로 저장하고 다음 실행 시 복원한다.
- 모터와 로드셀 통신 속도는 UI에서 제거하고 모두 115200 bps로 고정한다.
- v2는 하드웨어 없이 화면과 직렬 명령을 시험할 수 있는 `--demo` 모드를 제공한다.
- v2는 VS Code 실행 설정과 향후 EXE 생성을 위한 PyInstaller spec 파일을 포함한다.

## 확인된 주의 사항

- GUI 제목에는 현재 보드가 “Arduino Uno”로 표시되어 실제 UNO R4 Minima 명칭과 다르다.
- `main.py`와 `main_1.py`는 동일한 내용으로 보이며 여러 이전 버전 파일이 함께 존재한다.
- `main_2.py`는 인디케이터에 9600 bps를 사용하지만 `main.py`는 115200 bps를 사용한다. 실제 CI-1580A 설정 확인이 필요하다.
- GUI는 모터의 실제 위치 피드백 대신 경과 시간×명령 속도로 거리를 계산한다.
- GUI와 펌웨어 모두 하드웨어 리미트 스위치 처리 또는 하중 상한 자동 정지 로직이 확인되지 않는다.
- 소스의 일부 한글이 환경에 따라 깨져 보일 수 있다.

### 2026-09-03 · v3 응력-변형률 기능 추가

- 시험 설정에 **시편 직경(mm)**, **시편 초기 높이(mm)** 입력을 추가했다(원통형 가정, 기본값 D10 H5). 단면적 A = π(d/2)², 응력 = 힘/A (kPa), 변형률 = 거리/초기 높이로 계산한다.
- 그래프를 **응력-변형률**(기본)과 **힘-거리** 중 선택할 수 있고 시험 중에도 전환된다. Poroelasticity 모드에서는 X축 시간, Y축만 응력/힘으로 바뀐다.
- 상단에 실시간 응력·변형률과 **압축 탄성률 E**(변형률 5~15 % 구간 최소제곱 직선 기울기)를 표시한다. 시험 종료 시 최종값을 갱신한다.
- CSV 첫 줄에 시편 메타데이터 주석을 쓰고 `Strain (-)`, `Stress (kPa)` 열을 추가했다. 기존 3열(Time, Distance, Force)은 순서를 유지한다.
- 목표 거리가 시편 높이 이상이면 시작을 거부한다(압축판 바닥 충돌 방지). 직경·높이는 설정 파일에 저장된다.
- 데모 가상 젤을 0.2 mm 접촉, 약 20 kPa 선형 구간으로 바꿔 탄성률 표시를 확인할 수 있게 했다.
- 검증: 자동 테스트 11개 통과(응력·변형률 계산값, 직선 피팅 기울기 50 kPa 복원, 잘못된 시편 치수 거부, CSV 헤더). 데모 화면 캡처로 레이아웃 확인. `HydrogelStudio_4F.exe` 재빌드 후 `--demo` 실행 확인.

### 2026-09-16 · v3 응력 표시 버그 수정, 예상 시간·진행률 추가

- 버그 수정: 응력·변형률 표시가 기록 중(`_record`)에만 갱신되어, 압축이 끝난 뒤 힘이 크게 줄어도 응력 값이 마지막 기록값에 멈춰 있었다. 이제 로드셀 값이 들어올 때마다 현재 입력된 시편 직경으로 응력을 다시 계산해 표시한다. CSV와 그래프의 응력 계산식은 원래 정상이었다.

### 2026-09-22 · v3.0.1 전체 검증 및 수정

응력·힘·면적 계산 경로를 다시 검토했다. 응력 = 힘 ÷ 초기 단면적(π(d/2)², 공칭응력) 식 자체는 맞았고, 아래 항목을 고쳤다.

- **거리(변형률) 추정 오차 수정**: 이전에는 거리 = 경과시간 × 속도로 계산해 펌웨어의 가속 구간(2.5 mm/s²)을 무시했다. 1 mm/s에서 약 0.2 mm, 5 mm 시편이면 변형률 4 %p를 과대평가해 탄성률이 낮게 나왔다. 새 `hydrogel_app/motion.py`가 펌웨어와 같은 사다리꼴(짧은 이동은 삼각형) 프로파일로 위치를 계산한다. 예상 압축 시간과 진행률도 같은 모델을 쓴다.
- **평균 기록 시 거리 짝 오류 수정**: 평균 힘을 버킷 끝 시각의 거리와 짝지어 저장했다(0.2 samples/s, 0.5 mm/s면 2.5 mm 어긋남). 이제 시각·거리·힘을 함께 평균한다.
- **응력 라벨 지연 수정**: 시험 중 응력 표시가 기록 시점에만 갱신되어 낮은 기록 속도에서 힘과 어긋나 보였다. 로드셀 값이 올 때마다 갱신한다.
- 시험 중 0점 변경 차단(기록된 힘이 어긋나는 것을 방지). 이동·조그 속도가 펌웨어 상한(4000 steps/s = 5 mm/s)을 넘으면 시작 거부(넘기면 펌웨어가 속도를 잘라 거리 추정이 틀어짐).
- CSV를 매 줄 flush해 장시간 시험 중 프로그램이 죽어도 데이터가 남게 했다. CSV 메타데이터에 `stress=engineering F/A0, strain=distance/height0, distance=commanded trapezoid` 를 명시했다.
- 업데이트 교체 배치: 한글 경로에서 깨지지 않도록 ANSI(CP949)로 저장하고 PID 검사를 정확히 일치하도록 수정. 임시 폴더(한글 이름)에서 교체·재실행 동작을 실제로 시험해 통과. 시험 중에는 교체를 제안하지 않는다.
- 검증: 단위 테스트 23개 통과(프로파일 위치·시간, 속도 상한 거부, 0점 차단, 버킷 평균, 기록 거리≠t×v, CSV flush 포함). 데모 걸어보기 30여 항목 통과. exe 재빌드, v3.0.1 릴리스.
- 미검증: 실장비에서 가속 프로파일이 실제 위치와 얼마나 맞는지는 실측하지 않았다(AccelStepper 사양 기준).
- 참고: 응력은 공칭응력(초기 단면적 기준)이다. 하이드로젤은 압축 시 단면적이 넓어지므로 20 % 변형률에서 진응력은 약 20 % 낮다. 탄성률 산출에는 공칭응력을 쓰는 것이 관례라 그대로 두었다.

- 알려진 문제: 좁은 창에서 긴 상태 메시지가 표본 수와 시각 표시를 밀어낸다. 경고 메시지를 온전히 보여 주는 쪽이 낫다고 판단해 순서를 유지했다. 모터 전원 버튼의 전원 기호가 이 PC의 Windows 10 글꼴에서 네모로 보인다.
- 릴리스: 커밋 d5b3cd6, 태그 v3.1.0으로 GitHub에 푸시하고 릴리스를 등록했다. 토큰 없이 공개 API로 조회해, 각 층의 업데이트 모듈이 v3.1.0을 최신으로 찾고 v3.0.0·v3.0.1에서 새 버전으로 판정하는 것을 확인했다. 실제로 내려받은 exe는 로컬 exe와 SHA-256이 같았다.
